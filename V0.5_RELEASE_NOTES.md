# Verse v0.5.0 — Experience + Tester Release

## Added
- Candidate comparison (2–4 professionals)
- Server-backed recent searches/profile views for signed-in users
- Lightweight recent searches for public global search
- Music-industry synonym expansion (e.g. sound guy, keys guy, roadie, background score, tech director)
- Build My Crew: event brief -> recommended performance/technical/production lineup
- Conversion from crew recommendation into Band Builder seats
- Inline work-sample playback
- Safe YouTube, Spotify and SoundCloud embeds
- Local audio metadata + waveform generation using ffprobe/ffmpeg when available
- Local video metadata + thumbnail generation using ffprobe/ffmpeg when available
- Portfolio persistence for generated media metadata/waveform/thumbnail
- Admin Live Tester (`/admin/tester`)
- Full regression test suite and release gate

## Fixed during tester pass
- duplicate `const url` declaration in the server request handler
- uploaded local `/uploads/...` work samples being rejected by portfolio URL validation
- local waveform/thumbnail URLs being discarded by absolute-URL-only validation
- crew-plan persistence/conversion SQL shape issues caught before packaging
- candidate comparison/recent-activity wiring

## Important design principle
Build My Crew is deliberately deterministic/rule-based at this stage. A user can describe the event in layman terms without being forced to know whether they need FOH, monitors, a system engineer, stage manager or technical director. The recommendation can be edited after conversion to Band Builder; it is not presented as infallible AI.
